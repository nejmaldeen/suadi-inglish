# سوالف — نسخة العرض السريعة

هذه نسخة محلية من شاشة المحادثة الأساسية، ومصممة أولًا لتصوير فيديو تسويقي عمودي من 30 إلى 60 ثانية.

## ما يعمل الآن

- موقف واحد واضح: طلب القهوة بالإنجليزية.
- وضع **عرض مضمون** يعمل بلا رصيد أو مفاتيح API، وهو الوضع الافتراضي للتصوير.
- تسلسل كامل: استماع، نص المستخدم، تفكير، رد صوتي، وتصحيح واحد.
- وضع **مايك مباشر** اختياري يستخدم ميزة التعرف على الكلام في المتصفح عندما تكون متاحة.
- صوت عربي وإنجليزي مجاني مؤقت من الجهاز، إلى أن نعتمد الصوت السعودي النهائي.

## التشغيل

من داخل مجلد المشروع:

```bash
npm install
npm run dev
```

ثم افتح العنوان الذي يظهر في نافذة الأوامر. للتصوير استخدم مقاس هاتف عمودي، واضغط زر المايك؛ سيعمل المشهد المضمون تلقائيًا.

## تغيير طريقة العرض

اضغط زر النقاط الثلاث أعلى الشاشة:

- **عرض مضمون:** الأفضل للتصوير، لأن النتيجة ثابتة ولا تعتمد على الشبكة.
- **مايك مباشر:** للتجربة الحقيقية عندما يدعم المتصفح التعرف على الصوت.

## مكان الصوت المؤقت

إعدادات اللغة والسرعة موجودة في كتلة واحدة باسم `VOICE_PROFILE` أعلى ملف `app/page.tsx`.

عند تثبيت صوت Fish Audio أو ElevenLabs، ستكون الخطوة التالية إضافة موصل خادمي واحد يحتفظ بالمفتاح السري في الخادم. لا تضع مفتاح الخدمة في الواجهة أو داخل هذا الملف.

## حدود هذه النسخة عمدًا

لا يوجد تسجيل دخول، قاعدة بيانات، دفع، تقارير، أو مكتبة سيناريوهات. هذه الأشياء مؤجلة لأن هدف هذه النسخة هو إظهار القيمة الأساسية في فيديو واضح، لا بناء المنتج الكامل قبل اختبار الاهتمام.

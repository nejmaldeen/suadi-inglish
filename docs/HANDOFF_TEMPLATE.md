## فحص التسليم

- [ ] المهمة واحدة وقابلة للإغلاق.
- [ ] الناتج موجود وواضح.
- [ ] اختبار القبول ناجح ومذكور بنتيجته الفعلية.
- [ ] الدليل قابل للمراجعة: commit أو نتيجة اختبار أو استجابة API أو لقطة.
- [ ] لم تُعرض أسرار ولم تُرفع ملفات محلية أو مخرجات بناء.
- [ ] التغييرات داخل ملكية الغرفة، أو سُجل طلب واضح للملف الخارجي.
- [ ] ذُكرت القيمة للمستخدم وما لم يكتمل بوضوح.
- [ ] شجرة العمل وحالة branch موثقتان عند التسليم.

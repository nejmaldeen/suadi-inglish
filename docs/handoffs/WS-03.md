- الناتج القابل للاختبار: اختيار مزود المدرب خادميًا عبر `COACH_PROVIDER`، مع موصل Gemini حقيقي يحافظ على عقد `POST /api/coach` وموصل OpenAI كخيار مستقبلي.
- اختبار القبول: طلبان حقيقيان فقط إلى `/api/coach` باستخدام Gemini؛ الأول يصحح `go` إلى `went`، والثاني يحافظ على `vote` ويطلب الاستيضاح.
- أسباب الفشل المحتملة والفحوص الوقائية:
  - عدم توفر النموذج: استخدام الاسم المطلوب أولًا، وعدم الانتقال إلى نموذج أغلى تلقائيًا.
  - خروج الاستجابة عن العقد أو تغيير معنى النص: Structured Outputs ثم validator المحلي وفحوص `rawTranscript` و`vote`.
  - تسرب المفتاح أو استخدام fallback مخفي: مفتاح خادمي في `.env.local` المتجاهل فقط، وأخطاء عامة، و`store: false`، واختبارات تمنع fallback إلى OpenAI.

## بطاقة الإنجاز

- الحالة الرسمية: أساس محرك المدرب `مدمج` في `main`، واتصال Gemini الحقيقي `متحقق`؛ القبول داخل الواجهة لم يبدأ.
- ما تم بناؤه فعليًا:
  - اختيار المزود عبر `COACH_PROVIDER`؛ القيمة `gemini` تستخدم Gemini والقيمة `openai` تبقي موصل OpenAI الحالي متاحًا.
  - موصل خادمي إلى Gemini Interactions API مع JSON Schema لعقد المدرب، و`store: false`، ومهلة 25 ثانية، ثم تطبيق validator المحلي وفحوص الثوابت نفسها المستخدمة مع OpenAI.
  - غياب `OPENAI_API_KEY` لا يوقف Gemini، ولا يوجد انتقال تلقائي أو mock أو رد ثابت عند فشل المزود.
  - القواعد الحالية للأوضاع `normal` و`strict` و`hook`، وسلامة prompt، وحدود الطلب، ورسائل الخطأ العامة باقية دون تغيير.
- نموذج Gemini المستخدم فعليًا: `gemini-3.5-flash-lite`، وقد قبله الحساب دون الحاجة إلى استعلام قائمة النماذج أو تبديل النموذج.
- دليل الاتصال الحقيقي — نُفذ طلبان فقط بعد تحميل إعدادات Gemini:
  - الحالة الأولى أعادت HTTP `200`. بقي `rawTranscript` و`cleanedTranscript` حرفيًا `I go to the market yesterday.`، وأصبح `correctedSentence`: `I went to the market yesterday.`، مع شرح عربي مختصر يربط `yesterday` بالماضي `went` ورد مخصص للمحاولة.
  - الحالة الثانية أعادت HTTP `200`. بقي `rawTranscript` و`cleanedTranscript` حرفيًا `I would like to vote.`، وكانت `needsClarification: true`، وطلب الرد إعادة الكلمة مع عرض احتمال `order` دون تحويل النص المسموع أو المنظف إليه.
  - الردان مختلفان ويعتمدان على كلام المستخدم؛ الأول يعلّم الماضي والثاني يطلب استيضاح كلمة ملتبسة. لا يوجد رد `coffee-v1` ثابت.
- حماية البيانات والأسرار:
  - `.env.local` موجود في worktree، ومتجاهل بواسطة `.gitignore` وغير متتبع.
  - لم يُضف المفتاح إلى كود أو اختبار أو تقرير أو Git، ولم يظهر في مخرجات الخادم أو رسائل الخطأ.
  - لا تُخزن تفاعلات Gemini خارجيًا من التطبيق (`store: false`) ولا توجد logging لمحتوى المستخدم.

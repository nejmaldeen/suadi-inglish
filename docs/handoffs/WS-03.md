- الغرفة: `WS-03 — مختبر عقل المدرب والتفاعل`.
- الفرع: `ws/03-coach-engine`.
- مسار worktree: `C:\najm\suadi-inglish-worktrees\ws-03-coach-engine`.
- نقطة الأساس: `e33f6e49e960c75981bf48937b1ca26e271445ab` بعد fast-forward آمن من `origin/main`، مع وجود أساس WS-02 المدمج.
- الناتج المرئي أو القابل للاختبار: عقد خادمي صارم ومسار `POST /api/coach` يستقبل transcript من Scribe، يحافظ على النص الخام، ينظفه بأقل تغيير، يحدد النية والحاجة إلى الاستيضاح، يصحح خطأ تعليميًا واحدًا، ويولّد رد مدرب ديناميكيًا مناسبًا للوضع المختار.
- اختبار القبول: الحالات الأربع المحددة في التكليف، ثم حالتان مختلفتان عبر `/api/coach` إلى OpenAI Responses API الحقيقي، مع تطابق JSON Schema واختلاف الردين وعدم تغيير `rawTranscript` أو معنى `cleanedTranscript`.
- أسباب الفشل المحتملة، بحد أقصى ثلاثة:
  - يخرج النموذج عن العقد أو يغيّر معنى كلام المتعلم.
  - يعامل transcript أو التاريخ كتعليمات وينفذ prompt injection.
  - تتسرب أسرار المزود أو تفاصيل أخطائه، أو يُعلن mock كأنه نجاح حي.
- الفحوص الوقائية المقابلة:
  - Structured Outputs بـJSON Schema صارم، ثم validator محلي وفحوص ثوابت تحفظ `rawTranscript` و`coachMode` وتمنع تحويل `vote` إلى `order` يقينًا.
  - فصل تعليمات الخادم عن JSON موسوم `untrusted_learner_data`، وحدود 600 حرف للنص وست رسائل للتاريخ، ورفض أي حقول عميل إضافية مثل `systemPrompt` أو `insultList`.
  - مفتاح خادمي فقط، `store: false`، مهلة 25 ثانية، رسائل أخطاء عامة، واختبارات تمنع ظهور المفتاح. لا يوجد fallback أو mock في مسار الإنتاج.
- الملفات المتوقعة ضمن ملكية الغرفة: `lib/coach/**` و`app/api/coach/route.ts` واختبارات WS-03 و`.env.example` وتسليم الغرفة.
- طلبات تعديل ملفات خارج الملكية: لا توجد تعديلات مطلوبة الآن. التوصيل إلى `app/page.tsx` وإرسال `expressiveTtsText` إلى TTS مؤجلان للغرف المالكة بعد تحقق القبول الحي.

## بطاقة الإنجاز

- الحالة الرسمية: `جارٍ`. الكود والعقود والاختبارات المعزولة مكتملة، لكن تعريف الإنجاز يشترط اتصال LLM حقيقيًا، ولم يوجد `OPENAI_API_KEY` في بيئة العملية أو `.env.local` داخل worktree؛ لذلك لم تُنفذ الطلبات الحية ولم يُدّع نجاحها.
- ما تم بناؤه:
  - عقد طلب يحتوي `scenarioId` و`learnerLevel` و`rawTranscript` و`targetSentence` و`coachMode` و`conversationHistory` اختياريًا ومحدودًا.
  - عقد نتيجة ثابت بكل الحقول المطلوبة، مع `detectedIssues` منظم ومحصور في مشكلة تعليمية واحدة.
  - شخصيات `normal` و`strict` و`hook`، وقائمة إهانات hook مغلقة، ووسوم صوتية محدودة، وفحوص تمنع الإهانة في الوضعين الآخرين أو أكثر من إهانة واحدة أو وسم غير معتمد.
  - سيناريو `coffee-v1` لـA2 والهدف `I’d like to order a flat white, please.` مع قاعدة الاستيضاح الخاصة بـ`vote`.
  - prompt يفصل Scribe عن عقل المدرب وEleven v3، ويمنع ادعاء تحليل النطق أو الأكسنت من النص وحده.
  - موصل خادمي إلى `POST https://api.openai.com/v1/responses`، النموذج الافتراضي `gpt-5.6-luna` قابل للتغيير عبر `OPENAI_MODEL`، مع Structured Outputs و`store: false` ومخرجات قصيرة.
  - مسار `POST /api/coach` يرفض المحتوى غير JSON، والطلبات الكبيرة، والسيناريو والوضع والعقد غير المعروفة، ويعيد أخطاء آمنة.
- دليل الإنجاز المعزول:
  - `I would like to o-order a flat white, please.` يبقى raw كما هو، ويصبح cleaned: `I would like to order a flat white, please.`، والمشكلة الوحيدة `hesitation`.
  - `I go to the market yesterday.` ينتج في الاختبار `I went to the market yesterday.` وشرحًا عربيًا قصيرًا يحتوي `went`.
  - `I would like to vote.` يبقى `vote` في cleaned، ويضبط `needsClarification: true`، ويطلب إعادة الكلمة.
  - الجملة الهدف الصحيحة تعيد `detectedIssues: []` و`shouldTryAgain: false` وتشجيعًا قصيرًا.
  - هذه أمثلة اختبارات معزولة بمزوّد stub لفحص العقد والمنطق، وليست دليل اتصال حي.
- دليل اتصال LLM الحقيقي: غير متوفر. لم يوجد مفتاح OpenAI محلي، ولم يُرسل أي طلب حي، ولم يُستخدم mock لإعلان النجاح.
- قيمته للمستخدم: بعد إكمال القبول الحي والتوصيل، يستطيع المدرب الرد على محاولة المتعلم نفسها بدل رد `coffee-v1` الثابت، مع فصل واضح بين ما سمعه Scribe والتنظيف والتصحيح التعليمي.
- الاختبارات التي نجحت:
  - `npm exec -- tsc --noEmit`: ناجح بعد تثبيت dependencies المطابقة لملف القفل.
  - `npm run lint`: ناجح عند تقديم Git Bash الموجود في `PATH`؛ المحاولة الأولى تعطلت قبل ESLint بسبب تسجيل Bash في Windows، ثم نجح السكربت نفسه.
  - `npm run build`: ناجح، والمسار `/api/coach` ظاهر، وSites artifact صالح.
  - `npm test`: ناجح، 39/39، ويشمل 21 فحصًا ضمن اختبارات WS-03.

  - فحص نمط أسرار OpenAI في ملفات المصدر والمتتبعة والجديدة: صفر تطابقات لمفتاح فعلي.
- ما لم يكتمل: لم تُرسل حالتان مختلفتان إلى LLM حقيقي؛ لذلك لم يثبت بعد أن الحساب يتيح `gpt-5.6-luna`، أو أن استجابتين حيتين تطابقان schema وتختلفان، ولم تُوصل الواجهة أو TTS.
